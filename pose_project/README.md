# Pose Tracker (School Project)

A website that finds the points on a person's body.
- Live camera mode
- Upload photo mode (offline)
- Upload video mode (offline)

## How to run
1. Install Python 3.10, 3.11 or 3.12 (from python.org).
2. Open a terminal in this folder and type:
       pip install -r requirements.txt
3. Start the website:
       python app.py
4. Open your browser and go to:  http://127.0.0.1:5000

## Files
- app.py              -> the Python brain (Flask + OpenCV + MediaPipe)
- templates/index.html -> the web page you see
- requirements.txt    -> list of things to install
